# Архитектура проекта

Проект построен на принципах чистой архитектуры.  

## Структура каталогов

- `src/api/` — маршруты и обработчики
- `src/models/` — SQLAlchemy-модели
- `src/schemas/` — Pydantic-схемы
- `src/services/` — бизнес-логика
- `src/databases/` — подключение к БД
- `alembic/` — миграции базы данных (Alembic)
- `src/tests/` — автоматические тесты (pytest)

## Взаимодействие компонентов

1. **Пользователь** отправляет запрос к API.  
2. **FastAPI** маршрутизирует его в соответствующий обработчик.  
3. Обработчик вызывает **сервисы**, которые работают с моделями SQLAlchemy.  
4. Изменения сохраняются в **PostgreSQL** (через SQLAlchemy).  
5. Для тестов используется **SQLite**.
