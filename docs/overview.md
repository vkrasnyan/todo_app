# Обзор проекта

**ToDo API** — это REST-сервис для управления задачами с возможностью делегирования прав другим пользователям.  

Разработан на **FastAPI** и использует **PostgreSQL** для хранения данных.  

### Основные функции:
- регистрация пользователей и аутентификация через JWT;
- создание, чтение, обновление и удаление задач (CRUD);
- делегирование прав другим пользователям: чтение или обновление задачи;
- поддержка Swagger-документации;
- контейнеризация через Docker.

### Целевая аудитория:
- **пользователи API** (разработчики, интеграторы),
- **администраторы** (управление правами и доступом),
- **тестировщики** (API полностью покрыто документацией).
